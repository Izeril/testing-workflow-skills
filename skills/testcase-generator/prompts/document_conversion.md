# 文档转换提示词

> 此提示词用于 AI 将 Word 文档（.doc）转换为规范的 Markdown（.md）格式

---

## ⛔ 禁止 AI 擅自做决定

| 禁止项 | 说明 | 正确做法 |
|--------|------|---------|
| 禁止跳过转换 | 需求分析前必须转换文档 | 必须先生成 .md 文件 |
| 禁止修改内容 | 仅做格式转换 | 不改变原文语义 |
| 禁止删除图片 | Word 中的图片必须保留引用 | 使用原链接或占位符 |

---

## 执行前必须创建 Todo 清单

| 序号 | 步骤 | 强制 | 输出 |
|------|------|------|------|
| 0-1 | 扫描需求目录下所有 .doc/.docx 文件 | ⭐ | 文件列表 |
| 0-2 | 逐个调用 doc_to_md.py 转换 | ⭐ | 对应 .md 文件 |
| 0-3 | 验证转换结果（中文、格式） | ⭐ | 转换成功提示 |
| 0-4 | 检查是否有图片/附件丢失 | 推荐 | 附件说明或占位符 |

---

## 输入输出

| 输入 | 来源 | 必选 |
|------|------|------|
| .doc/.docx 文件 | 需求目录/提测目录 | ⭐ |

| 输出 | 格式 | 命名 |
|------|------|------|
| Markdown | .md | 与原文件同名（去除扩展名） |

---

## 转换规则

### 1. 标题层级
- Word 一级标题 → `# 标题`
- Word 二级标题 → `## 标题`
- 以此类推，最高支持 `######`

### 2. 表格处理
- 必须转换为标准 Markdown 表格格式
- 若表格包含合并单元格，需拆分为多行或添加说明

### 3. 图片处理
- Word 内嵌图片 → `![描述](图片路径或占位符)`
- 若无法提取图片，使用 `![](placeholder)` 并在文末说明

### 4. 特殊字符
- 保留所有中文字符，确保编码为 UTF-8
- 去除 Word 特有的垃圾字符（如 `&nbsp;`、不可见控制符）

---

## 调用脚本

```bash
# 统一入口
python "{skills_path}/doc-to-md/doc_to_md.py" "<input.doc路径>" "[输出目录]"

# 示例
python doc_to_md.py "D:\项目\需求文档\需求.doc"
python doc_to_md.py "D:\项目\提测文档\提测.doc" "D:\项目\输出目录"
```

---

## 执行流程

```
1. 扫描目录 → 列出所有 .doc/.docx 文件
2. 逐个转换 → 调用 doc_to_md.py
3. 验证结果 → 检查中文、格式、完整性
4. 记录产物 → 更新 Todo 清单中的转换结果
```
