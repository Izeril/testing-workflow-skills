# 外部接口测试模式

> 适用涉及外部接口调用的需求，AI 推导测试点时参考

---

## 🔌 接口调用测试

### 1. 正常调用

| 测试场景 | 验证要点 |
|---------|---------|
| 接口正常返回 | 正常调用返回预期结果 |
| 参数传递正确 | 参数是否正确传递 |
| 返回值解析正确 | 返回值是否正确解析 |
| 调用顺序正确 | 多接口调用顺序 |

### 2. 参数验证

| 测试场景 | 验证要点 |
|---------|---------|
| 必填参数缺失 | 必填参数缺失是否拦截 |
| 参数类型错误 | 参数类型错误是否拦截 |
| 参数值范围 | 参数超范围是否拦截 |
| 参数编码 | 特殊字符编码处理 |

---

## ⚠️ 接口异常测试

### 1. 调用失败

| 测试场景 | 验证要点 |
|---------|---------|
| 接口超时 | 超时阈值、重试次数、告警触发 |
| 接口失败 | 失败后降级处理、告警触发 |
| 返回格式错误 | 格式错误解析处理 |
| 返回状态异常 | 异常状态码处理 |

### 2. 网络异常

| 测试场景 | 验证要点 |
|---------|---------|
| 网络中断 | 网络中断重试/告警 |
| 域名解析失败（DNS） | DNS 失败降级处理 |
| SSL 证书异常 | SSL 异常处理 |

---

## 🔄 重试与降级

### 1. 重试机制

| 测试场景 | 验证要点 |
|---------|---------|
| 自动重试 | 失败后自动重试次数 |
| 重试间隔 | 重试间隔时间 |
| 重试告警 | 重试失败告警触发 |
| 重试终止条件 | 达到重试上限终止 |

### 2. 降级机制

| 测试场景 | 验证要点 |
|---------|---------|
| 服务降级 | 外部服务不可用时降级 |
| 缓存降级 | 降级后使用缓存数据 |
| 默认值降级 | 降级后返回默认值 |
| 降级告警 | 降级触发告警 |

---

## 📊 接口监控

| 测试场景 | 验证要点 |
|---------|---------|
| 调用日志 | 调用日志是否记录关键信息 |
| 响应时间监控 | 响应时间是否监控 |
| 失败率监控 | 失败率是否监控告警 |
| 服务等级协议（SLA）达标监控 | 服务等级协议达标情况监控 |
