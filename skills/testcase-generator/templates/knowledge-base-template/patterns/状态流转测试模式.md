# 状态流转测试模式

> 适用涉及状态流转的需求，AI 推导测试点时参考

---

## 🔄 状态展示测试

### 1. 状态值展示

| 测试场景 | 验证要点 |
|---------|---------|
| 各状态展示文案 | 各状态值对应的展示文案正确 |
| 状态图标/颜色 | 状态图标、颜色标识正确 |
| 状态排序 | 状态列表排序正确 |
| 状态筛选 | 状态筛选功能正确 |

### 2. 状态历史

| 测试场景 | 验证要点 |
|---------|---------|
| 状态变更记录 | 状态变更历史记录 |
| 变更时间记录 | 变更时间是否记录 |
| 变更原因记录 | 变更原因是否记录 |
| 变更人记录 | 变更人是否记录 |

---

## 🔁 状态流转测试

### 1. 正常流转

| 测试场景 | 验证要点 |
|---------|---------|
| 状态流转触发 | 流转条件触发后状态变更 |
| 流转方向正确 | 状态流转方向符合设计 |
| 流转顺序正确 | 状态流转顺序符合流程 |
| 流转后处理 | 流转后相关处理执行 |

### 2. 非法流转

| 测试场景 | 验证要点 |
|---------|---------|
| 非法流转拦截 | 非法流转方向被拦截 |
| 条件不足拦截 | 流转条件不足被拦截 |
| 权限不足拦截 | 无权限流转被拦截 |
| 拦截提示正确 | 拦截后提示正确 |

---

## 📏 状态边界测试

### 1. 状态边界

| 测试场景 | 验证要点 |
|---------|---------|
| 状态翻转触发 | 状态翻转条件触发验证 |
| 状态有效期边界 | 有效期边界状态翻转 |
| 状态过期处理 | 过期状态自动处理 |
| 状态闭环验证 | 状态流转闭环验证 |

### 2. 状态持久化

| 测试场景 | 验证要点 |
|---------|---------|
| 状态存储正确 | 状态值正确存储 |
| 状态变更持久化 | 变更后状态持久化 |
| 状态一致性 | 多处状态值一致 |
| 状态恢复 | 异常后状态恢复 |

---

## ⚠️ 状态异常测试

| 测试场景 | 验证要点 |
|---------|---------|
| 并发状态变更 | 并发变更是否正确处理 |
| 状态变更失败 | 变更失败回滚处理 |
| 状态锁定 | 关键状态锁定保护 |
| 状态死锁 | 死锁状态检测处理 |
