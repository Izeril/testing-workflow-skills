# 通用测试模式

> 适用所有需求的通用测试场景模板，AI 推导测试点时参考

---

## 🔍 功能测试模式

### 1. 主流程验证

| 测试场景 | 验证要点 |
|---------|---------|
| 正常流程完整执行 | 从开始到结束完整流程验证 |
| 分支流程处理 | 各分支路径执行验证 |
| 流程中断恢复 | 流程中断后能否恢复 |

### 2. 数据验证

| 测试场景 | 验证要点 |
|---------|---------|
| 数据完整性 | 数据是否完整存储/展示 |
| 数据准确性 | 计算结果、状态值是否准确 |
| 数据一致性 | 多处数据是否一致 |
| 数据时效性 | 数据是否及时更新 |

### 3. 字段验证

| 测试场景 | 验证要点 |
|---------|---------|
| 必填字段校验 | 必填字段缺失是否拦截 |
| 字段类型校验 | 字段类型错误是否拦截 |
| 字段长度校验 | 超长字段是否截断/拦截 |
| 特殊字符校验 | 特殊字符是否正确处理 |

---

## ⚠️ 异常测试模式

### 1. 输入异常

| 测试场景 | 验证要点 |
|---------|---------|
| 空输入 | 空值是否正确处理 |
| 超范围输入 | 超范围值是否拦截 |
| 格式错误 | 格式错误是否提示 |
| 非法字符 | 非法字符是否过滤 |

### 2. 操作异常

| 测试场景 | 验证要点 |
|---------|---------|
| 操作中断 | 中断后状态是否正确 |
| 重复操作 | 重复操作是否幂等处理 |
| 并发操作 | 并发是否正确处理 |
| 顺序错误 | 顺序错误是否拦截 |

### 3. 系统异常

| 测试场景 | 验证要点 |
|---------|---------|
| 服务异常 | 服务不可用时降级处理 |
| 网络异常 | 网络中断是否重试/告警 |
| 资源不足 | 内存/存储不足是否处理 |
| 超时处理 | 超时是否正确处理 |

---

## 📏 边界测试模式

### 1. 数值边界

| 测试场景 | 验证要点 |
|---------|---------|
| 最小值边界 | 最小值是否正确处理 |
| 最大值边界 | 最大值是否正确处理 |
| 边界附近值 | 边界±1值处理 |
| 空值边界 | 空值/null处理 |

### 2. 时间边界

| 测试场景 | 验证要点 |
|---------|---------|
| 有效期开始边界 | 开始时间点状态 |
| 有效期结束边界 | 结束时间点状态翻转 |
| 跨天边界 | 跨天时间处理 |
| 跨月/跨年边界 | 跨周期处理 |

### 3. 状态边界

| 测试场景 | 验证要点 |
|---------|---------|
| 状态翻转触发 | 状态翻转条件触发验证 |
| 状态持久化 | 状态变更后是否持久化 |
| 状态一致性 | 多处状态是否一致 |

## 🔐 安全测试模式

### 1. 权限控制

| 测试场景 | 验证要点 |
|---------|---------|
| 无权限拒绝 | 无权限用户操作被拒绝 |
| 权限隔离 | 不同权限用户数据隔离 |
| 越权防护 | 越权操作被拦截 |

### 2. 数据安全

| 测试场景 | 验证要点 |
|---------|---------|
| 数据加密 | 敏感数据加密存储 |
| 数据脱敏 | 日志/展示脱敏处理 |
| 数据防泄露 | 数据泄露防护 |

|---------|---------|
