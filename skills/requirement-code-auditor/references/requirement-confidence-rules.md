# 需求事实置信度与人工门禁

`confidence = 0.30×原文明确度 + 0.25×结构完整度 + 0.20×来源可追溯性 + 0.15×跨文档一致性 + 0.10×规范化确定性`。

每个分量只能取 `0`、`0.5` 或 `1`。高置信度为 `>=0.80`，中置信度为 `0.60–0.79`，低置信度为 `<0.60`。

- 高置信度且可比较：允许正式分类。
- 中置信度且可比较：缺失或不一致必须标记人工复核。
- 低置信度：只允许证据不足或需求待确认。
- 核心事实低于 0.80、互斥值、关键数值歧义、超过 20% 核心事实不可比较或 schema 修复后仍失败时，设置 `human_review_required=true`。
