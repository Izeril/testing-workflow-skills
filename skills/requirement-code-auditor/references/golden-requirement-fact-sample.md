# 分页、排序、错误码黄金样本

## 输入

来源 `需求.md` 的“查询规则”：

> 查询记录默认按申请时间最新优先展示，每页 20 条。页码超过最后一页时返回空列表。
> 未登录用户调用接口时返回错误码 AUTH_001，并提示“请先登录”。

## 期望事实

- `sorting:申请时间:desc`：字段“申请时间”，方向 `desc`，高置信度，可比较。
- `pagination:page_size:20`：每页 20 条，越界返回 `empty_list`，高置信度，可比较。
- `error:未登录用户调用接口:auth_001`：错误码 `AUTH_001`、文案“请先登录”，核心、高置信度、可比较。

三条事实都必须保存来源文档、锚点、原文短句、五个确定性置信度分量和原因。黄金期望不加载到正式候选提取上下文。
