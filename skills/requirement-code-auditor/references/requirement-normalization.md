# 需求事实规范化

## 目录

1. 类型映射
2. 稳定键
3. 冲突

## 类型映射

- 翻页、分页查询、每页展示 → `pagination`，分别保留页码起点、每页条数、最大页数和越界行为。
- 倒序、最新优先、从新到旧 → `sorting.direction=desc`；升序、正序 → `asc`。
- 提示、报错、返回码、错误编号 → `errors`；错误码和错误文案分别保留。

## 稳定键

优先使用接口方法与路径、表名、配置键、任务名、排序字段与方向、分页属性和值、错误条件与错误码。不得从任意业务关键词猜测键。

## 冲突

同一来源的同义事实去重；不同文档中同一冲突键出现互斥值时保留全部事实并生成 `requirement_conflict`。规范化不得添加原文未声明的条件。
